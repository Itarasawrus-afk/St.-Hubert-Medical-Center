# Data Documentation

This directory is intended to hold the database documentation and validation summaries used by the St. Hubert Medical Center BI project.

## Recommended contents

- `ERD_Relationships.txt` — entity relationship descriptions.
- `curated_columns.tsv` — curated table and column reference.
- `table_row_counts.csv` — table row-count summary.
- `primary_key_validation.csv` — primary-key validation results.
- `foreign_key_validation.csv` — foreign-key validation results.
- `fk_relationship_audit.csv` — foreign-key relationship audit.
- `final_audit_metrics.csv` — final database audit metrics.
- `material_mapping_summary.csv` — material mapping summary.
- `material_table_column_inventory.csv` — material table column inventory.

Review all documentation for patient identifiers, personal information, local file paths, and other sensitive details before committing.
